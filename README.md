# Personal Portfolio Website

A modern single-page portfolio website designed for a professional career profile.

## Run locally

From this folder, start a static web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customize

Update the profile details in `index.html` including:

- Name and title
- About section
- Experience entries
- Project highlights
- Contact links

## Deployment for a public recruiter link

To make it public, deploy the folder to a static hosting service such as:

- GitHub Pages
- Netlify
- Vercel
- Azure Static Web Apps

After deployment, update personal links and resume URL in the contact section before sharing with recruiters.
